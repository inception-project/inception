[[sect_settings_reference_document]]
= 🧪 Reference document sidebar

====
CAUTION: Experimental feature.
====

The reference document sidebar opens another document from the project in a read-only editor
alongside the document being annotated.

.Settings related to the reference document sidebar
[cols="4*", options="header"]
|===
| Setting
| Description
| Default
| Example

| `ui.reference-document.enabled`
| Whether to enable the reference document sidebar
| `false`
| `true`
|===
